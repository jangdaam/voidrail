# Voidrail 개발 기록 (인수인계용)

> 다른 AI/사람에게 넘겨 기획을 이어 가기 위한 문서. 2026-11-16 기준 상태.
> 저장소: https://github.com/jangdaam/voidrail · 플레이: https://jangdaam.github.io/voidrail/
> 기획서(원본): Claude Docs "Voidrail 게임 기획서"

## 1. 한 줄 요약

**허공(보이드)에 떠 있는 절차적 섬들 사이를 끝없는 선로로 달리는, 걸어 다닐 수 있는 3D 저폴리 기차.** 최대 4인 협동. 기차를 운영(연료·속도)하며 자원을 줍고, 습격과 추적을 막으며 세계의 비밀을 풀어 가는 게임.

- 출발점: *Voidtrain*의 컨셉(허공 + 기차)만 빌림. 자원 경제·구조는 따라가지 않음.
- 비주얼: *PEAK*의 저폴리 스타일 오마주 (평면 셰이딩, 정점 색, 텍스처 없음).
- 운영 감각: *Sea of Thieves*처럼 여럿이 배(기차)를 나눠 운영. 단 **아늑함 비중이 크고 중간중간 긴장**.

## 2. 확정된 기획 결정

| 항목 | 결정 |
|---|---|
| 인원 | 최대 4인 협동. 음성은 디스코드 사용 → 게임 내 음성 없음 |
| 목표 | 세계의 비밀 풀기. 이야기 축 A "끊어진 연결망" (확정 아님, 더 고민 중) |
| 보스 | 테라리아처럼 지역 보스 여러 개 (미구현) |
| 캠페인 | 계속 이어짐. **전원 사망 또는 기차 전파 시 진행 정지** → 별도 퀘스트를 깨거나 걸어 다니며 기차를 수리해야 재개 (미구현) |
| 긴장 요소 | 습격 이벤트 위주 (구현) + 선로 추적자 (구현) |
| 섬 | 대부분 "잠깐 내려 줍기". 가끔 특별한 섬(내려서 전투·퍼즐) |
| 지역 | 정해진 로케이션 없음. **6개 지역이 순환 반복** (구현) |
| 특별한 섬 | 퀘스트 목표가 선택된 상태에서 다음에 그 지역에 가면 등장 (미구현) |
| 개발 순서 | **싱글 먼저** 다 해 보고 나서 친구 초대 (멀티는 기반만 유지) |
| 시작 기차 | 아주 작게: 투박한 3량, 차콜/철/구리 색 |
| 연료 | **나르기형**: 연료차의 장작을 삽으로 퍼서 화실에 넣음. 결정(크리스탈) 자원은 삭제 |
| 플레이 리듬 | 평소엔 **서행하며 자원 회수·연료 절약**, 위협(추적자)이 오면 연료를 태워 가속 |
| UI | 평소엔 **체력 바만**. 퀵바·도구는 H를 눌러야 등장. 안내 글자는 F3(디버그)에서만 |

## 3. 현재 플레이 가능한 것

### 조작
| 키 | 동작 |
|---|---|
| WASD · Shift · Space | 이동 · 달리기 · 점프 (무중력에선 위로) |
| 마우스 | 시점 (첫 클릭 시 마우스 고정) |
| E | 상호작용: 레버(출발/정지) · 연료 상자(배낭 목재 넣기) · 화실 |
| Z / X | 속도 목표 낮추기/높이기 |
| H | 도구 꺼내기/넣기 (꺼내기 전엔 퀵바도 숨김) |
| 1–4 · 휠 | 1 렌치 · 2 삽 · 3 권총 · 4 갈고리 |
| 좌클릭 | 도구 사용 |
| R | 안전줄 감기 (기차 밖에서 숙소칸으로 복귀) |
| V | 1인칭 ↔ 외부 시점 |
| P | 같이 타기 창 (방 만들기·참가·초대 링크) |
| F3 또는 ` | 디버그 모드 (상태 표시, 시드/지역/시간/습격/추적 버튼, 측정 패널) |
| M | 소리 |

### 기차 (3량, 앞→뒤)
1. **기관실**: 보일러, 지붕만 있는 열린 운전실, 화실(불빛이 불 세기 연동), 압력계 바늘, 레버.
2. **연료차**: 장작 상자(로그 더미가 남은 양만큼 보임), 공구 상자, 난간.
3. **숙소칸**: 지붕·벽 있는 실내(안전), 침대·탁자·램프, 옆문. **뒷문 밖 지붕 없는 전망대** (추적자 사격 자리).
- 차량 폭 4.4m. 차량 간 이동 시 시점 강제 회전 없음.
- 기차 밖은 무중력 + 안전줄(R로 감기).

### 보일러 (나르기형) — `BOILER`
- 연료 상자 시작 5삽, 최대 20삽. 화실 시작 연료 40 (= 1삽).
- 화실 연료 → 불 세기(0~1) → 압력 상승. 속도가 빠를수록 압력·연료 소모 ↑.
- 압력 15% 이하면 최고 속도 0(서서히 멈춤), 75%에서 최고 40m/s. 95% 넘으면 안전밸브 증기.
- 불 잘 때면 지속 가능한 속도 ≈ 26m/s. 모아 둔 압력으로 순간 40m/s.
- 시작 연료로 대략 4~6분 주행.
- 배낭 목재 2개 = 상자 1삽 (연료 상자에서 E).

### 도구
| 슬롯 | 도구 | 현재 기능 |
|---|---|---|
| 1 | 렌치 | 근접 2피해. **수리 기능은 자리만** (고장 시스템 미구현) |
| 2 | 삽 | 상자에서 퍼기 → 화실에 넣기. 근접 1피해 |
| 3 | 권총 | 히트스캔, 1피해, 반동·궤적·불꽃 |
| 4 | 갈고리 | 35m 내 떠다니는 자원을 겨냥해 끌어오기 |
- 1인칭 손 모델은 별도 패스로 그려 벽을 뚫지 않음. 다른 사람에겐 아바타 손에 도구가 보임.

### 자원
- 섬 주변에 **목재(62%) / 고철(38%)**이 떠다님. 몸으로 스치거나 갈고리로 회수 → 배낭.
- 고철은 아직 **쓸 곳이 없음** (제작/수리 재료 후보).

### 습격: 공허 진드기 — `RAID`
- 기차가 달린 시간 기준 첫 습격 100초, 이후 160~260초 간격. 4마리부터 매번 +1 (최대 9).
- 행동: 노출된 사람(열린 칸·기차 밖·전망대)을 맴돌다 돌진해 물기(14피해), 아니면 기차에 달라붙어 **압력을 갉음**(마리당 0.012/초). 숙소칸은 안전하지만 기차가 느려짐.
- 체력 3 (권총 3발·렌치 2대). 처치 시 고철 조각이 처치한 사람에게 빨려 옴.

### 추적자: 선로 포식자 — `CHASE`
- 선로를 타고 뒤에서 쫓아오는 거대한 지네형 괴물. 첫 등장 210초, 이후 220~340초.
- 400m 뒤에서 출발, 14 → 22m/s로 가속. 560m 벌어지면 포기, 120초 지나면 물러남.
- 따라잡히면 맨 뒤 칸 들이받기: 압력 −28%, 감속, 숙소칸 인원 22피해.
- 전망대에서 머리를 쏘면 발당 3.5m 밀림, 14발이면 물러나며 고철 5개.
- 화면 위 거리 막대(평소 화면에도 표시).

### 체력 / 사망
- 체력 100, 피격 5초 후 초당 4 회복. 0이 되면 숙소칸 침대에서 깨어나고 배낭 절반 손실.
- (기획의 "전원 사망 시 진행 정지"는 미구현)

### 타격감
- 히트스톱(맞을 때 0.035초, 처치 0.07초), 조준점 X 표시(처치는 빨간색), 피해 숫자, 맞은 적 흰 번쩍임·찌그러짐·넉백, 처치 파편, 권총 반동, 화면 흔들림, 피격 시 붉은 비네트. 전투 효과음 모두 Web Audio 합성.

### 세계
- 결정론적 시드 노이즈로 섬·나무·구름·랜드마크·선로 생성. 청크 단위 시간 분할 생성(프레임 끊김 방지), 품질 프리셋 자동 하향.
- 6개 지역(생태계)이 순환: 각자 나무 종류·날씨·랜드마크·화음.
- 낮/밤 순환, 날씨 입자(실내에선 숨김), 고래 같은 연출.

## 4. 멀티플레이 (구현됨, 실제 인터넷 테스트는 미완)
- **Trystero**(WebRTC, Nostr 시그널링) P2P. 서버 없음. GitHub Pages 정적 배포로 동작.
- 방장 = peer id 가장 작은 사람. 방장이 기차·보일러·진드기 AI·추적자를 계산.
- 아바타 이동: 비신뢰 무순서 데이터채널, 44바이트 스냅샷 20Hz, 지연 적응 Hermite 보간(목표: 끊김 없는 아바타). 자세한 건 `docs/NETCODE.md`.
- 동기화 주기: 기차·보일러·추적자 4Hz, 진드기 10Hz(손님은 예측+보간).
- 손님의 공격은 방장에게 판정 요청(연출은 즉시). 처치 보상은 처치한 사람에게.
- 테스트(같은 브라우저 내 지연·손실 흉내): 진드기 위치 오차 ~1m, 동기화·피해·보상 정상.

## 5. 기술 구조

- 순수 브라우저: **Three.js r160** (vendor 폴더), 빌드 도구 없음, ES 모듈. 코드 약 3,300줄.
- 배포: main에 push → GitHub Actions → Pages. 배포 시 모든 모듈 주소에 `?v=커밋` 붙여 캐시 섞임 방지.

```
index.html          UI·스타일·importmap
js/config.js        모든 튜닝 수치 (BOILER, RAID, CHASE, TOOLS, BIOMES, QUALITY …)
js/state.js         공유 상태 S
js/main.js          초기화·프레임 루프·멀티 연결
js/world.js         청크 계획/생성, 자원(픽업)
js/track.js         선로 곡선·프레임
js/train.js         기차 3량 모델·충돌 박스·같은 평면 자동 정리(z-fighting 방지)
js/player.js        1인칭 물리(차량 로컬 좌표), 무중력·안전줄, 카메라
js/boiler.js        연료→불→압력→최고 속도
js/interact.js      바라보는 대상 선택 (E)
js/tools.js         퀵슬롯·손 모델·삽/권총/갈고리/렌치
js/toolmodels.js    도구 모델
js/raid.js          습격·진드기 AI·체력·멀티 동기화
js/chaser.js        추적자
js/feel.js          타격감
js/env.js · weather.js · fx.js · audio.js · avatar.js · ui.js · mpui.js
js/net/             transport(Trystero/로컬 테스트) · clock · snapshot · interp · session
tools/              relay.mjs(로컬 시그널링), vendor.mjs
```

- 튜닝은 거의 전부 `js/config.js`에서 숫자만 바꾸면 됨.
- 디버그: `?debug` 또는 F3. `?prof`로 긴 프레임 구간 기록(`window.__prof`). `?net=local&lag=80&loss=.03&room=X`로 같은 브라우저 두 탭 멀티 테스트.

## 6. 개발 타임라인 (2026-11-16)

1. 2D 도트(Kingdom 오마주) 시안 → 3D 저폴리(PEAK 오마주)로 전환, 걸어 다니는 기차 + 1인칭.
2. 안정화: 성능(시간 분할 생성·품질 자동), z-fighting 원천 차단(같은 평면 자동 밀어내기).
3. 멀티플레이 기반(끊김 없는 아바타 보간) + GitHub Pages 배포.
4. 기획 정리 (위 2절).
5. 기차 폭 확장, 차량 이동 시 시점 강제 회전 제거.
6. 시작 기차 3량으로 단순화.
7. 보일러(나르기형) + 도구 4종, 결정 자원 삭제.
8. 습격(진드기) + 타격감 → 디버그 모드 분리.
9. 추적자(선로 포식자) + 숙소칸 전망대.
10. 습격·추적자 멀티 동기화.
11. UI 최소화: H 홀스터, 안내 글자 F3 전용, 퀵바 번호만, 시작 카드 제거, P로 같이 타기, 캐시 무효화.

## 7. 알려진 문제 · 미확인

- **크롬에서 간헐적 멈칫거림** 보고됨(사용자 PC: AMD Radeon 780M 내장 그래픽, 배율 1.75). 원인 미측정. 후보: 고해상도 렌더(픽셀 배율)·그림자·로그 깊이 버퍼의 GPU 부하, 새 셰이더 첫 컴파일, `backdrop-filter` 블러 UI. F3 측정 패널로 확인 필요.
- 실제 인터넷 너머 멀티플레이는 아직 미검증(로컬 흉내만).
- 렌치 수리, 고철 사용처, 전원 사망 시 진행 정지, 저장 기능 없음.
- 평소 화면에 안내가 거의 없어 처음 하는 사람이 조작을 모를 수 있음 (튜토리얼/힌트 설계 필요).

## 8. 다음 기획 후보 (논의용)

1. **고장·수리**: 압력 과다·습격·들이받기로 부품 손상(증기 누출, 바퀴, 연결부) → 렌치로 수리, 고철 소모. 기획의 "기차가 다 부서지면 걸어서 수리" 규칙과 연결.
2. **고철 사용처**: 기차 칸 추가·업그레이드(연료 상자 확장, 장갑판, 탄약), 제작대.
3. **캠페인 정지 규칙**: 전원 기절/기차 전파 → 정지 상태와 복구 퀘스트.
4. **특별한 섬 + 퀘스트 선택**: 목표를 고르면 다음 해당 지역에서 섬 등장, 내려서 전투/퍼즐.
5. **지역 보스** 6종 (지역별 테마).
6. **아늑함 요소**: 숙소칸 꾸미기, 요리·휴식 버프, 낚시 같은 서행 중 놀이.
7. **저장/불러오기** (캠페인 지속).
8. **이야기 축** "끊어진 연결망" 구체화: 선로가 왜 있는지, 섬·추적자·진드기의 정체.
9. 처음 하는 사람을 위한 최소 안내(UI 최소화 방침과 균형).

## 10. 방향 전환 (2026-11-17): 지하 산업도시 — `city` 브랜치

베타테스트 의견(더 어둡고 위기감 있게)에 따라 세계관을 바꿨다. **허공의 섬 → 열차가 작아 보이는 거대한 지하 산업도시를 빠져나가는 이야기.**
이 절 위의 내용(섬·생태계·보일러·진드기·포식자·도구)은 이전 버전(`main`)의 기록이며, `city` 브랜치에서는 코드를 걷어냈다.

확정된 방향

## 12. 열차 순서 · 안드로이드 개편 · 회수 드론 (2026-11-18) — `city` 브랜치
- **열차 순서**: 운전차(앞) → 동력차/배터리 칸(가운데, 지붕 없음) → 객실(뒤). 운전실과 객실을 오가려면 반드시 드러난 배터리 칸을 지나야 한다. 비상 크랭크는 배터리 칸 뒤쪽 옆으로 옮김(통로 확보).
- **잡을 수 있는 부품 (`train.GRIPS`, `registerGrip/clearGrips`)**: 안드로이드는 좌표가 아니라 부품 목록에서 그때그때 고른다. 정비 구역에서 객차 설비가 바뀌면 그 객차의 부품만 다시 등록하면 된다.
  - `rail` 배터리 칸 옆 난간 → 넘어 들어옴 / `bar` 운전차·객실 옆 손잡이 봉+발판(새로 붙임) → 매달려 버티다 위로 옮겨 잡음 / `gutter` 지붕 옆 가장자리 → 지붕 / `ledge` 배터리 칸 쪽 지붕 끝 모서리 ↔ 배터리 칸 바닥.
- **안드로이드 동작**
  - 손 고정: 잡은 손은 스프링을 거치지 않고 부품 위 한 점에 박힘. 몸만 진자처럼 속도에 따라 뒤·바깥으로 쏠리고 선로 충격에 덜컥 튐.
  - 단계별 등반(2.4~2.9초): 오른손 → 몸 처짐 → 왼손 → 골반 상승 → 무릎 걸침 → 넘어와 웅크림 → 천천히 일어남. 봉→가장자리 옮겨 잡기, 모서리 뛰어 잡기, 등 돌려 매달려 내려오기도 같은 방식(키 포즈 `makeClimb/REACH/makeJump/makeLower`).
  - 좌표계 전환(`reroot`): 매달린 자리 → 바닥, 바닥 → 모서리 등 기준점을 바꿀 때 지금 자세를 새 기준으로 옮겨 담아 튀지 않음.
  - 걸음: 발을 통합 좌표에 실제로 디딤(미끄러짐 없음), 한 발씩 들고, 발을 드는 동안만 몸이 쏠려 나감 → '쿵… 쿵…'. 한쪽 다리를 절어 낮게 끌고 그쪽으로 디딜 때 푹 꺼짐. 한 팔은 반쯤 앞으로 뻗음. 속도 1.0m/s.
  - 고개: 톱니처럼 한 칸씩 걸리며 돌고(딸깍 소리), 몸과 상관없이 뒤까지 돌아감. 가끔 옆으로 꺾임. 손·머리·골반이 늘 미세하게 떪(체력이 낮을수록 심함).
  - 돌발: 예고 없이 굳어 부들부들 떨다가 비명과 함께 4.2m/s로 달려들어 빠른 내려치기. 경련(한 팔이 튐)도 무작위.
  - 공격: 팔을 머리 위로 치켜든 채 떨며 멈칫(.4~.6) → 한 번에 내리찍음 → 앞으로 쏠림. 1.75초.
  - 창 두드리기: 손잡이 봉에 매달린 채 안쪽에 사람이 있으면 빈손으로 창을 내리침.
  - 지붕에서 내려오기: 그때그때 뛰어내리기(착지점 제각각) 또는 모서리에 매달렸다 떨어지기. 지붕 위 사람에게는 배터리 칸 바닥에서 모서리로 뛰어 잡고 올라감.
- **회수 드론 (`js/drone.js`)**: 배터리를 노림.
  - 어둠 저편에서 탐조등 빛줄기(원뿔 + SpotLight, 미리 3개 만들어 세기만 조절)가 먼저 보이고 회전익 소리가 다가옴.
  - 열차 위를 좌우로 크게 가로지르며 앞뒤로 오가는 갈지자 비행. 가속 제한 조향이라 꺾을 때 관성으로 휘며 기울어짐. 가끔 사람 쪽으로 내리꽂는 척하다 솟구침. 빛에 사람이 걸리면 '삑삑삑' 하고 빛을 붙잡아 따라감.
  - 3~6번 맴돈 뒤 배터리 랙으로 급강하해 집게를 물림(2.4초, 빛이 붉게). 그동안 쏘거나 걷어차면 떨어져 나감. 다 물면 25~35%를 뜯어 달아나며, 달아나는 중 격추하면 되찾음.
  - 체력 4, 격추 시 고철 2·부품 1. 디버그 버튼 '회수 드론 🛸'.
- 시험: `window.__camHook(camera)`로 카메라를 열차 밖에 둘 수 있음. `android.__hangOn(car, kind, x, side)`, `__placeOn(x, level)`.

## 13. 추락 방지 · 안전줄 · 안드로이드 출현 확대 · 부위별 피격 (2026-11-18 새벽) — `city` 브랜치
- **객차 사이 연결 통로 (`train.JOINTS`)**: 매 프레임 두 차량 끝점을 이어 발판·옆 난간·가림막을 늘였다 줄임. 플레이어 충돌에도 포함 → 커브에서 벌어져도 틈으로 떨어지지 않음(흔들림은 그대로).

- **좁은 선로**: 철교·고가 상판 7.6m → 4m(열차 폭보다 좁음), 상판 난간 제거. GPT 일반 구역(`ordinary-harbor.js`) 상판도 같은 폭으로 줄이고, 선로→작업장 계단 위에 좁아진 상판까지 잇는 층계참을 붙임 (사용자 요청으로 GPT 코드 최소 수정, `(Claude)` 주석).
- **안전줄**: 무중력 유영·순간이동 복귀 삭제. 떨어진 자리 차량 가장자리에 최대 4m 줄로 매달림 — 중력, 속도² 맞바람으로 뒤로 쏠림, 덜컹임, 선로 바닥에 닿으면 끌리며 다침. **R 을 누르고 있는 동안 1.15m/s 로 감겨** 끝까지 감기면 올라옴. 줄은 18마디 베를레 사슬(차량 기준)로 두껍게 그림.
- **총알·빛 차폐 (`train.rayTrain`)**: 총알은 객차 벽·지붕·바닥에서 막히고 불꽃(유리창은 통과). 드론 탐조등은 그림자(512px, 열차·안드로이드만 드리움)로 객차 실내에 새지 않고, 빛기둥 원뿔도 처음 닿는 객차 면에서 잘림.
- **드론**: 크기 60%, 빛 반경·각도 축소. 터널에선 생성 안 됨, 터널 입구에 다다르면 솟구쳐 물러남.
- **안드로이드 출현**
  - 최대 14기, 무리 간격 9~20초. 앵커마다 여러 기.
  - 터널: 보행로를 따라 이미 달려오는 무리(runner), 천장을 거미처럼 기어오는 것(spider), 정비문, 천장 매달림.
  - 트인 구간: 선로 위를 정면으로 달려옴(느리면 앞코로 뛰어 붙고, 빠르면 치여 날아감) / 상판 아래를 손으로 짚으며 다가옴(climber) / 문형 크레인 위에서 뛰어내림(gantry) / 작업 발판에서 일하다 알아채고 달려옴(work) / 선로로 이어진 계단을 우르르 올라옴(stairs: 일반 구역은 GPT 설계의 작업장 계단, 그 밖엔 직접 만든 계단). 계단이 길면 열차가 지나가기 전에 닿도록 이미 중간에서 출발.
- **열차 위 행동**: 운전실·객실 문으로 드나듦(통로 구간은 가운데로만). 돌발 질주는 드물게(14~26초 간격, 확률 낮춤). 골반·가슴·머리를 구로 보고 충돌 상자에서 밀어내 객차와 겹치지 않음, 서로도 밀어냄.
- **부위별 피격**: 머리·몸통·팔 2마디·다리 2마디 캡슐로 판정. 머리는 홱 젖혀지며 꺾임, 팔은 튕겨 나가고 잡고 있던 손을 놓침, 다리는 주저앉고 절게 되며 두 번 맞으면 기어서 옴, 몸통은 통째로 밀리며 허리가 꺾임. 쓰러진 몸(랙돌)도 맞은 관절이 튕김. 죽는 순간에도 맞은 관절이 먼저 꺾여 나감.
