# Voidrail

최대 4명이 정비 열차를 몰아 거대한 지하 산업도시를 빠져나가는 1인칭 협동 게임 (프로토타입).
열차 한 대가 작아 보이는 지하 도시를, 전력을 아끼고 주워 가며 기계들을 뿌리치고 달린다.

## 실행

빌드가 필요 없다. 저장소 폴더에서 정적 웹 서버만 띄우면 된다.

```
python -m http.server 8000        # 또는: npx serve .
→ http://localhost:8000
```

주소 옵션: `?seed=1234`(시드 고정) · `?s=600`(그 지점에서 시작) · `?debug`(디버그 모드로 시작) · `?room=코드`(같이 타기).

## 조작

| 키 | 동작 |
|---|---|
| WASD · Shift · Space | 이동 · 달리기 · 점프 |
| 마우스 · 좌클릭 | 시점 · 사격 (개인 화기, 포탑에 앉으면 포탑) |
| E | 상호작용: 레버, 사다리·해치, 포탑, 배터리 랙, 크랭크(누르고 있기). 대상이 없으면 손 닿는 자원 집기 |
| Q | 주행 레버를 바라보고: 단수 내리기 |
| R · F | 재장전 · 발차기 |
| V · P · M | 외부 시점 · 같이 타기 · 소리 |
| F3 (또는 `) | 디버그 모드: 상태 표시, 안드로이드 소환·전력 0%·충전 버튼 등 |

출발: 운전차 조작대에서 가운데(빨간) 브레이크 레버를 풀고, 왼쪽(구리색) 주행 레버로 단수를 올린다.
시스템 설명은 `docs/DEVLOG.md` 11절, 맵 생성 규칙은 `README-DESIGN.md`.

## 첫 주행 구간 (구역 하나 = 1400m, 끝나면 한 층 위의 다음 구역으로 이어짐)

| 거리 | 공간 |
|---|---|
| 0–110m | 정비 터널. 늑골 기둥·배관·작업등·정비문 (배치는 시드마다 다름). 굴절로 앞을 가림 |
| 110–170m | 하역장 끝 벽을 뚫고 나온 회랑. 한쪽 벽이 열리며 갱도가 보이기 시작 |
| 170–450m | 철교. 왼쪽은 끝이 안 보이는 방벽(캣워크·주 배관·큰 밸브), 오른쪽은 폭 300m 갱도 |
| 450–700m | 하역장 안 수평 주행. 크레인 아래로 화물판이 천천히 오르내림 |
| 700–1000m | 경사 상승 40m (최대 약 11°). 굴곡을 돌며 건너온 철교가 아래로 보임 |
| 1000–1400m | 상부 정비 통로. 중간 개구부로 수직 갱도와 승강대가 잠깐 보임 |

첫 구역의 하역장은 시드와 상관없이 같고, 이후 구역은 좌우·폭·상승 높이가 시드로 달라진다.

## 구조

```
index.html          화면 요소·스타일
js/config.js        조정 수치 (속도, 품질, 안개)
js/track.js         선로 곡선과 구역 설계값 (전진형: X로 나아가며 높이·좌우가 변함)
js/city.js          도시 생성: 선로 청크(터널) + 구역 세트(하역장), 불빛, 움직이는 설비
js/geo.js           Mesher (상자·배관을 메시 하나로 합치는 도구), 공용 재질
js/scene.js         렌더러·안개·배경·기본 조명
js/train.js         열차 3량 모델·충돌
js/player.js        1인칭 이동 (차량 로컬 좌표), 카메라
js/env.js · fx.js · audio.js · interact.js · avatar.js · ui.js · mpui.js
js/net/             멀티플레이 (P2P, 방장 기준 동기화) — docs/NETCODE.md
```

## 성능 방침

- 그림자 없음, 픽셀 배율 상한(높음 1.5), 가벼운 Lambert 재질.
- 구조물은 재질별 메시 몇 개로 합쳐 그리기 호출을 줄임. 원경은 단순한 상자 실루엣.
- 작업등은 대부분 빛나는 면 + 번짐 점 + 덧셈 원판(가짜 조명). 실제 광원은 카메라에 가까운 2~4개만 돌려 씀.
- 하역장은 앞 터널을 달리는 동안 여러 프레임에 나눠 미리 생성.

배포: `main` 브랜치에 올리면 GitHub Pages로 자동 배포된다. 이 작업은 `city` 브랜치에 있어 라이브 페이지에는 반영되지 않는다.
