# Voidrail

절차적으로 생성되는 허공 위를 달리는 기차에서, 친구와 함께 1인칭으로 돌아다니는 협동 탐험 프로토타입.
*Voidtrain* 의 콘셉트와 *PEAK* 의 저폴리 스타일을 오마주했다.

- 끝없이 이어지는 선로와 떠다니는 섬. 6개 지역, 지역별 랜드마크와 날씨가 있다. 모두 시드 하나에서 생성되며 이미지·모델 파일이 없다.
- 걸어 다닐 수 있는 시작 기차 3량: 기관차(개방형 운전실 + 보일러), 연료차, 숙소칸.
- 기차 밖으로 뛰어내리면 무중력 유영 상태가 된다. 안전줄을 달고 떠다니는 자원을 주울 수 있다.
- **같이 타기:** WebRTC P2P 멀티플레이. 서버 없이 방 코드만으로 접속한다.
- 소리는 모두 Web Audio 로 합성한다 (레일, 증기, 바람, 지역 앰비언트).

## 실행

빌드 단계는 없다. 저장소 폴더를 웹 서버로 열면 된다. ES 모듈이라 `file://` 로 직접 열면 동작하지 않는다.

```bash
npm run serve           # http://localhost:8000
# 또는
python3 -m http.server 8000
```

## 같이 타기

1. 오른쪽 아래 **👥 같이 타기** → **새 방 만들기**를 누른다.
2. **초대 링크 복사**로 친구에게 링크를 보낸다. 친구가 링크를 열고 탑승하면 자동으로 같은 방에 들어온다.
3. 먼저 들어온 사람(🚂 기관사)이 기차 위치, 시간, 세계의 기준이 된다.

설계와 측정 결과는 [docs/NETCODE.md](docs/NETCODE.md) 에 정리했다.

## GitHub Pages 배포

1. 이 저장소를 GitHub 에 push 한다.
2. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꾼다.
3. `main` 에 push 할 때마다 `.github/workflows/pages.yml` 이 자동으로 배포한다. 주소는 `https://<사용자명>.github.io/<저장소명>/` 이다.

## URL 옵션

| 옵션 | 설명 |
|---|---|
| `?room=CODE` | 해당 방에 자동 참가 |
| `#debug` | FPS·드로우콜·네트워크 상태 패널 |
| `?net=local&lag=120&jitter=40&loss=0.05` | 같은 브라우저 탭끼리 가짜 네트워크로 넷코드 시험 |
| `?signal=ws://host:port` | 공용 릴레이 대신 자체 신호 서버 사용 (`npm run relay`) |

## 보일러 (나르기형)

연료차 상자에는 장작이 5삽 들어 있습니다. 삽(2)을 들고 상자를 바라보며 좌클릭으로 퍼서, 기관실 화실 앞에서 좌클릭(또는 E)으로 넣습니다.
화실 연료가 탈수록 압력이 오르고, 기차가 빠를수록 압력을 많이 씁니다. 압력이 15% 밑으로 떨어지면 기차는 서서히 멈추고, 95%를 넘으면 안전밸브가 증기를 뿜습니다.
떠다니는 목재는 갈고리(4)로 끌어와 배낭에 넣고, 연료 상자에서 E로 넣으면 목재 2개가 1삽이 됩니다. 수치는 `js/config.js`의 `BOILER`에서 조절합니다.

## 습격

기차가 달리는 동안 몇 분마다 공허 진드기 떼가 날아옵니다(디버그 버튼 `습격 ⚔`로 바로 시작).
진드기는 열린 칸(기관실·연료차)이나 바깥에 있는 사람을 물고, 아니면 기차에 달라붙어 증기관을 갉아 압력을 떨어뜨립니다.
권총(1), 렌치(2), 삽(1)으로 잡으면 고철 조각을 떨어뜨립니다. 체력이 0이 되면 숙소칸에서 깨어나고 배낭 절반을 잃습니다. 수치는 `js/config.js`의 `RAID`.

## 추적자 (선로 포식자)

몇 분마다 선로를 타고 400m 뒤에서 쫓아옵니다(화면 위 거리 막대, 디버그 버튼 `추적 🐛`). 점점 빨라지지만 최고 속도(약 79km/h)는 기차보다 느립니다.
- 화실을 잘 때서 속도를 올리면 따돌릴 수 있고(560m), 2분이 지나면 지쳐서 돌아갑니다.
- 따라잡히면 맨 뒤 칸을 들이받아 압력이 크게 떨어지고 숙소칸에 있던 사람이 다칩니다.
- 숙소칸 뒷문 밖 전망대에서 권총으로 머리를 쏘면 한 발마다 뒤로 밀리고, 14발이면 물러나며 고철 5개를 흘립니다.
평소엔 천천히 달려 연료를 아끼며 자원을 줍고, 위협이 올 때만 속도를 올리는 흐름을 의도했습니다. 수치는 `js/config.js`의 `CHASE`.

## 멀티플레이에서의 전투

기관사(방장)가 진드기 AI·추적자·보일러를 계산하고, 다른 승객은 상태를 받아 보여 줍니다(진드기 10Hz, 기차·추적자 4Hz).
- 진드기는 노출된 승객 중 가장 가까운 사람을 노리고, 물린 사람에게만 피해가 갑니다.
- 다른 승객의 사격·근접 공격은 기관사에게 보내 판정하고, 맞는 연출은 쏜 사람 화면에서 바로 나옵니다.
- 처치하면 모든 화면에 파편이 튀고, 고철 조각은 처치한 사람에게만 날아가 들어갑니다.
- 추적자에게 들이받히면 그때 숙소칸에 있던 모든 승객이 다칩니다.
